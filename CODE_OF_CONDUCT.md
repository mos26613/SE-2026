# Code of Conduct

## Our pledge

We want this project to be a welcoming, respectful and harassment-free place for everyone, whatever their background, identity or level of experience.

## Expected behaviour

- Be respectful and considerate in all communication.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and the team.
- Credit the work and ideas of others.

## Unacceptable behaviour

- Harassment, insults or discriminatory language.
- Personal or political attacks.
- Publishing others' private information without permission.
- Any other conduct that would be inappropriate in a professional setting.

## Enforcement

Report concerns privately to the project maintainers. All reports will be reviewed and handled confidentially.

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
