# Architecture Decision Records

An ADR records one significant technical decision: its context, the options considered, and the consequences.

## How to add one

1. Copy [`template.md`](template.md) to `NNNN-short-title.md`, using the next number.
2. Fill it in with status **Proposed**.
3. Open a pull request so the team can discuss it.
4. Once it's agreed, set the status to **Accepted** and merge.

ADRs are never deleted. If a decision changes, write a new ADR and mark the old one **Superseded by NNNN**.
