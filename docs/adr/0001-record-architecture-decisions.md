# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-14

## Context

We need to remember why significant technical decisions were made, so that current and future team members can understand them and revisit them when circumstances change.

## Decision

We will use Architecture Decision Records (ADRs), stored in `docs/adr/` and based on [`template.md`](template.md). Each ADR is proposed and discussed through a pull request.

## Consequences

- Decisions and their reasons are versioned alongside the code.
- Adding an ADR takes a little extra effort for each significant decision.
